# Evidence index

Every file here is generated by `python -m vlalab.analysis.build` (and `vlalab.analysis.verify`) from `runs/`.
Configurations are in [../experiments/](../experiments/). The model is `pi05_libero` (π0.5 fine-tuned on LIBERO,
checkpoint `gs://openpi-assets/checkpoints/pi05_libero`), evaluated on LIBERO-Long (`libero_10`).

**Differences from the original evaluation (π0.5 paper / openpi's reported 92.4 %):**

1. **Episodes.** 20 per configuration (initial states 0–1 of each task), 40 for the baseline (states 0–3). The reported number uses 50 per task (500). At about 90 % success with 20 episodes, only gaps of ~36 points are detectable ([tables/arms.md](tables/arms.md)).
2. **Suite.** LIBERO-Long only, plus a 10-episode `libero_spatial` smoke run.
3. **Hardware.** Kaggle Tesla T4: 1.6–1.9 s per policy call, against 73 ms on an RTX 4090 in the π0 paper. The simulator waits for the policy, so latency changes wall time, not success.
4. **Checkpoint vs paper model.**
   - `pi05_libero` ignores the robot state (`discrete_state_input=False`) and predicts 10-action chunks instead of 50.
   - It doesn't use π0.5's high-level subtask decoding.
   - It is fine-tuned on the four LIBERO suites, so evaluation tasks are training tasks. This is not a generalization test.
5. **Software.**
   - Our pipeline, sampler, server and evaluation loop replace openpi's (equivalent per `verify.md`).
   - Server timing includes the device-to-host copy; openpi's built-in timer under-counts.
   - The Kaggle image needed Ubuntu 24.04 package renames and a gsutil workaround ([../kaggle/job.sh](../kaggle/job.sh)).
6. **Unchanged from the reference evaluation script.** Seed 7, fixed LIBERO initial states, 10 settle steps, 180° image rotation, 224 px images, replan every 5 actions.

**Sampling sensitivity.** Moka pots, initial state 0, fails at 10 and 1 steps (replan 5) and succeeds at 3 steps, at replan 10, and at 3 steps + replan 10. Soup + sauce, initial state 0, fails only at replan 10. With `noise=stream`, a different call count shifts the noise of every later episode, so these flips mix configuration and noise ([../src/vlalab/policy/rng.py](../src/vlalab/policy/rng.py); `noise=episode` separates them).

## Definitions

- **Stall:** end effector moved < 1 cm over the last 4 policy calls (20 env steps).
- **Gripper command switch:** the executed open/close command changes.
- **Sustained grasp:** a close held for ≥ 10 steps.
- **Re-plan disagreement:** mean L2 (translation dims) between the previous chunk's not-yet-executed actions and the new chunk's actions for the same steps.

All are in [analysis/features.py](../src/vlalab/analysis/features.py).
